Incremental exports compare complete file inventories with the last published export. MirrorHub keeps a copy of each export's metadata on its state volume, so the pickup tool may move exports out of the drop folder. Directories the tool has emptied are removed automatically.

If an export was lost on the way, use Incremental since with the last export the receiver has applied (python -m mirrorhub.importer status). The newest {{ meta_keep }} metadata copies per repository are kept (MIRRORHUB_EXPORT_META_KEEP); an older receiver state needs a full export imported with --rebase.

If files are missing or damaged on the receiver, upload its repair request with Repair export: the export resends only those files (plus the changes since the receiver's export) instead of a full export.
